NSRCG II — SHADOWRUN THIRD EDITION INTEGRATION PREVIEW
Build date: November 5, 2026 (US Eastern) / November 6 UTC
Status: DEVELOPMENT ONLY — Windows runtime not yet verified

WHAT CHANGED
- Built a new source-based Windows x64 GUI prototype with an embedded reference catalog.
- Recovered original NSRCG data from the user's 2005 installer (not downloaded from GitHub).
- Used finsterdexter/sr3data as a technical reference for source-data decoding; implemented a separate converter with strict book filtering and field provenance.
- Used apampuch/PySRCG (MIT) as an implementation reference for SR3 priority tables, metatype modifiers, and derived values. Rules were reimplemented and tested independently.
- Catalog has 9,000+ parsed SR3-oriented records, with 15 rejected sourcebooks excluded from the approved reference list. SR2 has NO rules engine; earlier-edition SOURCEBOOK content may remain as SR3 reference where approved.
- Basic SR3 priority selection and validation, attributes, racial modifiers, Reaction, Combat/Spell Pools, cyberware Reaction/Initiative and indicative Essence/Magic.
- Legacy .sr3 import now retains the original byte sequence as base64 in the saved JSON for future re-import, while surfacing a usable subset of character fields.
- HTML export uses Unicode UTF-8 and automatic HTML escaping.
- PDF button uses locally installed Microsoft Edge's headless print-to-PDF feature. Edge must be installed; that UI path has not been tested on Windows.
- Adds an unsaved-changes warning on replacement/exit.

HOW TO TEST ON WINDOWS 10/11 (64-BIT)
1. Extract the preview ZIP to a folder.
2. Run NSRCG_II_SR3_integration_preview.exe. This preview requires no Python or VB6 runtime.
3. Create a new character and change the five priority dropdowns (one each A-E), race, and attributes. Select Recalculate / Validate.
4. Search the catalog for Datajack, Ares, a spell, or a skill. Select a result and choose Add selected.
5. Add a skill manually with a rating between 1 and 6.
6. Save to JSON and reopen the file. Verify fields and imported data.
7. Choose Import .sr3 and select sample/archStreetSamurai.sr3. Its derived values should be Reaction 11, Initiative 11+3D6, Combat Pool 7 and Essence 0.09.
8. Export HTML and check in a modern browser.
9. Export PDF if Microsoft Edge is installed; inspect the output for Unicode and layout problems.
10. Check the unsaved-changes prompt on New, Open, Import or Close after editing.

KNOWN DEVELOPMENT LIMITATIONS
- This new build is reconstructed from recovered data and reviewed repository source. It is not a binary patch to the earlier Go preview: that preview's SOURCE CODE was not included in its archive.
- The Win32 GUI has been cross-compiled, not runtime-tested on Windows. Common dialogs, GUI interactions, layout, high-DPI and Edge PDF printing must be checked on Windows before release.
- The PDF export depends on locally installed Microsoft Edge. It is not a fully self-contained PDF engine, but it works entirely offline when Edge is available.
- Full SR3 legality, racial/attribute limits, contacts, specialization costing, spells, adept powers, edge/flaw interactions, bioware index, cyberware grade/capacity, decking/rigging, Karma/advancement, and character finalization are incomplete. Basic calculations are NOT complete rules validation.
- Legacy priority decoding is provisional; original bytes are preserved for later faithful mapping. Unsupported fields may not yet appear in the editor, even though they remain archived in the JSON save.
- Data decoder left 37 original data lines unresolved because of malformed legacy formats. The audit is in TEST_REPORT.txt.
- Data catalogs include material from FASA-era sourcebooks. Permission to distribute that data publicly is separate from software licensing. For personal local testing only.
- Compatibility with JSON files generated by the *previous* NSRCG II preview has not been established. Back up all previous characters before testing.
- The Ally Spirit creator, second unfinished stub, GM viewer, standalone dice roller, Excel export, and SR2 rules are not included.
