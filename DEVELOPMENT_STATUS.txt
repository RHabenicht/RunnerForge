RunnerForge 0.2.0 development checkpoint — 2026-11-13
Development build, not a complete SR3 rules release.

Implemented:
Priority and adjustable Build Point creation; 14 Companion metavariants;
custom-race editing and reusable definitions; linked-attribute skill costs;
Knowledge/Language pools; creation specialization and literacy ratings;
selected skill/item editing and removal; equipment quantities and prices;
Spell Point purchases/sales; Edge/Flaw cost accounting; cyberware grade costs;
Bio Index and its effect on starting Magic; character notes and karma;
career snapshots, skill/specialization/attribute advancement history;
new skills and multiple specializations purchased with karma;
all stored character groups in HTML/PDF; per-user Windows installer.
Starting-ghoul BP creation, explicit infection results and GM substitutions,
pre-transformation skill costs/pools, adjusted limits and doubled implant Essence.
Career-acquired infection, geasa and condition/combat automation remain outside
this implementation.
Seven shapeshifter species with independent forms, special creation budgets,
form-specific derived values and separate attribute advancement. Seal table
conflicts require a recorded GM choice. Combat/condition effects remain
reference information. See docs/SPECIAL_CHARACTERS_2026-11-13.md.
Editable contact/lifestyle purchase accounting; legacy contacts and prepaid
lifestyle totals mapped into editable/exported entries with raw data retained.
Prices and free-contact eligibility remain user-reviewed rather than inferred.
35 checked equipment entries from Sprawl Survival Guide and Target: Awakened
Lands; 6,484 active entries. See docs/EQUIPMENT_REVIEW_2026-11-12.md.

Verification:
Local Go tests/vet, Windows cross-build and four Python tests pass.
Windows Server 2022 CI exercises native race and entry editors, save/load,
point budgets, PDF creation, executable launch, installer build/install/launch,
and uninstall while retaining a user-created save.
Equipment Windows acceptance run 43324415437 passed all steps, including
installer build/install/launch/uninstall. See CODEX_HANDOFF.md.
Windows Server testing does not establish Windows 10/11 desktop acceptance.

Still required for complete SR3 coverage:
- Career-acquired ghoul infection and otaku creation.
- Compound implants, cyberlimb/cybereye capacity, augmentation stacking,
  attribute modifiers, cultured bioware rules and equipment dependencies.
- Full magical eligibility, foci bonding, spirits, initiation and tradition/
  aspect restrictions. Edge/Flaw effects beyond their point accounting.
- Remaining advancement: spells/foci, training and automatic karma-pool progression.
- Vehicle/deck customization and comprehensive availability/legality checks.
- Book-by-book verification of catalog values and complete legacy field fidelity.
- Direct Windows 10/11 desktop and visual/DPI acceptance.
- Locate/import the user's recalculated race sheet; it has not been imported.
