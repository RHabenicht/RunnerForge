# Optional custom races

NightLife-Rebuilt-Races.dat contains 16 user-defined races. It is JSON in a separate .dat file, not the original NSRCG DAT syntax. It is not embedded in the default race list and never replaces published races.

In RunnerForge, click **Load race…**, open **NightLife-Rebuilt-Races.dat** from the installed **race-packs** folder, then select a **(NightLife)** race in the Race list. Loading makes all 16 available for the current session. Load the pack again after restarting to browse the full list. A saved character embeds its selected definition and can be reopened without the pack.

Dwarf/Ork variants cost 5 BP / Priority D. Elf/Troll variants cost 10 BP / Priority C. There is no metavariant surcharge. Halfling costs 5 BP / D; Sasquatch costs 15 BP / B. Priority selections must still be assigned uniquely by the player. Defaults remain unchanged.

The file preserves the supplied spellings (Koborkuru, Formori, Menehene, Night Ones). Attribute modifiers and creation costs are implemented. Special rules are descriptive notes: vision, conditional Body bonuses, dermal armor, reach, ranged penalties, running multipliers, empathy, allergies, sound mimicry, speech restrictions, dual nature and Sasquatch's doubled Essence loss are not automatically adjudicated by this pack. Inherent allergies grant no automatic flaw points. Do not add the same inherent allergy again as a point-granting flaw.

No running multiplier is inferred for entries where the user did not supply one. Dermal armor and conditional resistance bonuses remain separate from the listed base attribute modifiers.
